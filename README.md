# AI-Assisted Multi-Agent Application Development: a case study

The portfolio case study for a six-week capstone project: an AI tool that drafts a fund's calendar of
reporting deadlines, with a human specialist approving every rule.

The site is written as the project happens. A new chapter is added at the end of each phase.

All data shown is fictional.

## Running it locally

```bash
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:4321).

## Built with

[Astro](https://astro.build), hosted on [Vercel](https://vercel.com).
